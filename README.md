# SERENE AI — AI-Powered Multimodal Emotional Expression Platform

An integrated emotional well-being platform combining **Natural Language Processing (NLP)**, **Facial Expression Recognition (FER)**, and **Speech Emotion Recognition (SER)** into a unified multimodal fusion engine.

---

## 🚀 Key Highlights & Architecture

- **Text Emotion Analysis**: Analyzes text sentiment and emotion using `j-hartmann/emotion-english-distilroberta-base` with high-fidelity local NLP fallback.
- **Facial Expression Recognition**: Webcam snapshot or image upload analyzed via `trpakov/vit-face-expression` (Vision Transformer).
- **Voice Emotion Recognition**: Browser microphone recording (MediaRecorder API) or audio file upload analyzed via `Dpngtm/wav2vec2-emotion-recognition`.
- **Multimodal Late-Fusion Engine**: Dynamically weights and normalizes probability vectors across available modalities (Text: 40%, Face: 35%, Voice: 25%), detects inter-modal discrepancies, and computes consensus emotions.
- **Well-being & Music Recommendations**: Emotion-tailored actionable habits and curated YouTube ambient/calming music suggestions.
- **Emotional Journal & Analytics**: Real-time trend visualizations using Recharts, sleep vs. stress correlation analysis, and PDF journal export via PDFKit.
- **Zero-Friction Evaluation**: Runs out-of-the-box in local/demo mode with 1-click instant login and persistent session state, with instant seamless support for live Firebase & Hugging Face credentials when supplied.

## 🛠️ Quick Start (Running Locally)

### 1. Backend Server
```bash
cd backend
npm install
npm start
```
*Backend runs on: `http://localhost:5000`*

### 2. Frontend Client
```bash
cd frontend
npm install
npm run dev
```
*Frontend runs on: `http://localhost:5173`*

## 🔐 Environment Configuration (Optional)

To connect live cloud services, populate the `.env` files:

### Backend (`backend/.env`):
```env
PORT=5000
FRONTEND_URL=http://localhost:5173
HF_TOKEN=hf_your_token_here
FIREBASE_PROJECT_ID=your-project-id
FIREBASE_CLIENT_EMAIL=your-service-account-email
FIREBASE_PRIVATE_KEY=your_firebase_private_key_placeholder
FIREBASE_DATABASE_URL=https://your-project-id-default-rtdb.firebaseio.com
```

### Frontend (`frontend/.env`):
```env
VITE_API_URL=http://localhost:5000
VITE_FIREBASE_API_KEY=your-web-api-key
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_DATABASE_URL=https://your-project-default-rtdb.firebaseio.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your-sender-id
VITE_FIREBASE_APP_ID=your-app-id
```
